onnx_light.onnx_core.compressed_tensors
=======================================

Exposes the native C++ checkpoint adapter through nanobind. Python only
provides the public names; packing, validation and conversion run in C++.
See :ref:`the support matrix and adapter boundary <l-compressed-tensors-checkpoints>`
for supported layouts, the pinned upstream revision and resource limits.

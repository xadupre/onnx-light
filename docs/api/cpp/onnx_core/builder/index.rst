builder
=======

The ``builder`` sub-namespace of ``onnx_core`` (``core::builder``) hosts
:cpp:class:`GraphBuilder`, its read-only :cpp:class:`GraphGraph` index, and
the pattern-based graph optimizer (:cpp:class:`PatternOptimization` and the
companion :cpp:class:`PatternRegistry`).

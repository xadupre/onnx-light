onnx_light.onnx_core.gguf
=========================

Imports native GGML blocks into standard ``EncodedValueProto`` values,
with exact reconstruction and byte-preserving export. This is not a
standalone GGUF container API.
See :ref:`the versioned support matrix <l-gguf-blocks>`.

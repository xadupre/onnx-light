graph_manipulations.h
=====================

``onnx_proto/common_functions.h``), including
:cpp:func:`onnx_light::CollectExternalInputs`,
:cpp:func:`onnx_light::CollectRemainingInputs` and
:cpp:func:`onnx_light::CollectNodeInputs`.
